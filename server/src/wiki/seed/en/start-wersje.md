# Supported game versions

The launcher starts any Minecraft version, including older ones, snapshots and modded versions. The **SlashClient HUD** mod – and with it the HUD, cosmetics, friends and chat in game – works on the versions in the table below.

## Versions with SlashClient HUD

| Game version | Java |
|---|---|
| 26.3 | 25 |
| 26.2 | 25 |
| 26.1, 26.1.1, 26.1.2 | 25 |
| 1.21.11 | 21 |
| 1.21.9, 1.21.10 | 21 |
| 1.21.6, 1.21.7, 1.21.8 | 21 |
| 1.21.5 | 21 |
| 1.21.4 | 21 |
| 1.21, 1.21.1 | 21 |
| 1.20.5, 1.20.6 | 21 |
| 1.20.3, 1.20.4 | 17 |
| 1.20.1 | 17 |

The launcher downloads Java by itself; you do not need to install it.

## How it looks in the launcher

- When you pick a version in the wizard or in profiles, versions with the HUD are marked **SlashClient HUD**.
- Pick a version without it and the launcher says the HUD is not available there, and lists the versions that have it.
- The HUD works with Fabric and in the plain game (the launcher adds what it needs by itself). Your own mods go into a profile with a mod loader (e.g. Fabric).

## Versions without the HUD

On the other versions (e.g. 1.8.9, 1.12.2, 1.16.5) you play normally through the launcher, with mods and mod loaders, but without the HUD, cosmetics or chat in game. Friends and chat still work in the launcher.
