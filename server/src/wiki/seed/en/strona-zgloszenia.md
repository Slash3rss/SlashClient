# Reporting bugs

Found a bug in the launcher, the HUD or on the website? Report it at [slashclient.pl/bugs](https://slashclient.pl/bugs). Reports are public: before you write, check whether someone has already reported the same thing.

![The list of reports (Polish interface)](strona-zgloszenia.webp)

## The list of reports

- a search box and a status filter;
- 30 reports per page;
- the **New report** button.

## How to report a bug

1. Sign in on the website (see [Signing in](/wiki/start-konto)).
2. Click **New report**.
3. Write a title (4–120 characters) and a description (what you did, what happened, what you expected).
4. Attach a [link to your log](/wiki/strona-logi) and the launcher version, if you have them.
5. Send the report.

> The quickest way: when the game crashes, click **Report a bug** in the launcher. It shares the log and opens a report with the link to it and the launcher version filled in. The **Report a bug** button on a shared log's page does the same.

![A report with the team's answer (Polish interface)](strona-zgloszenie.webp)

## Statuses

| Status | What it means |
|---|---|
| **Open** | new, waiting to be checked |
| **Confirmed** | the team confirmed the bug |
| **Fixed** | the fix is in a new version |
| **Closed** | closed without a change |
| **Duplicate** | someone already reported the same |

The SlashClient team changes the status. The team's answers carry a **Team** badge.

## Replies

Anyone signed in can reply under a report (up to 4000 characters) – for example to say it happens to them too. You can delete your own report as long as nobody has replied; your own replies you can delete any time.

Need help rather than reporting a bug? See the [FAQ](/wiki/faq-czeste-pytania).
