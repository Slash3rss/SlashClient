# Community page and invites

## A community's page

Every public [community](/wiki/spolecznosc-spolecznosci) has a page at **slashclient.pl/s/*tag*** (or with the community's id). Private communities have no page.

![A community's page (Polish interface)](strona-spolecznosc.webp)

The page shows:

- the logo, name, `#tag`, member count and the **Verified** badge if the community has one;
- whether the community is **open** (anyone joins) or joined **on request**;
- the description, the community's game server address (if it set one), the founder and when it was founded;
- **How to join?** – in the launcher: **Friends** → **Communities** → **Discover communities**, search for the name;
- a reminder that community chat is not encrypted, and a **Download SlashClient** button.

A [player's profile](/wiki/strona-profil) that shows its communities links to this page too.

## A community invite

Community admins make links like **slashclient.pl/c/*code***. Opened in a browser, one shows an invite page:

![A community invite page (Polish interface)](strona-zaproszenie-spolecznosc.webp)

- the community's name and description, how long the link is valid (or "Never expires") and how many uses are left;
- a **Copy link** button;
- how to join: in the launcher, **Friends** → next to **Communities** click **Join with an invite** and paste the link or code.

A link works for a private community too. It does not work for banned people or when the community is full.

> A **/z/*code*** link is something else: a [SlashClient referral](/wiki/spolecznosc-polecenia) from a friend.
