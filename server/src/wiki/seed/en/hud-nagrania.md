# Screenshots, clips and replay

## Screenshot to clipboard

After **F2** the screenshot goes straight to the clipboard (paste it on Discord, say), and a small preview shows in the corner. From the preview you can send it to a SlashClient friend – the hint names the key. On by default (the **Screenshot to clipboard** card in Extras).

## Caption on screenshots

Writes into a corner of the screenshot (F2) where you stood, when, and on which server or in which world. The caption is drawn into the saved PNG.

- **Corner** – bottom left, bottom right, top left, top right.
- **Coordinates and dimension**, **Server or world** – what the caption says.

## Clips

Like ShadowPlay: the game keeps the last seconds of the screen in memory, and **F8** saves them as a video in the `clips` folder next to your screenshots. Copying the frames does not slow the game down. Off by default – switch it on with the **Clips** card in Extras.

![The clip settings](hud-opcje-clips.webp)

| Setting | Options |
|---|---|
| Clip length | 10–60 seconds |
| Resolution | 480p, 720p, 1080p, 1440p or as the window |
| Frames per second | 20, 30 or 60 |

> A higher resolution and more frames mean more memory and work in the background: a minute at 1080p and 60 frames takes about half a gigabyte.

## Instant replay

**F6** shows, in the game, what was on the screen during the last seconds – without leaving the game. It uses the same frames as the clips; with clips off it starts recording itself with the same settings. Off by default – the **Instant replay** card in Extras.

- **Replay length** – 15, 30, 45 or 60 seconds.
- **Pause singleplayer while watching**.

In the replay window:

| Key | What it does |
|---|---|
| Space | play / pause |
| ← / → | a frame back / forward |
| I / O | start / end of the selection |
| L | loop |
| Esc | close |

**Save as clip** and **Save selection** save all of it or the chosen part to the clips folder.

> The replay costs about 2–3 MB of memory per second (30 s is about 60–90 MB) and a little processor time in the background.
