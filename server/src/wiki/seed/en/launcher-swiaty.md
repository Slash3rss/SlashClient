# Worlds, screenshots, clips and configs

Every profile has two tabs for the game's files: **Worlds and screenshots** and **Configs**.

## Worlds and screenshots

At the top are four tabs and an **Import world** button.

### Worlds

The profile's worlds with their icon, game mode and when you last played. For each world:

- **Backup** – saves a backup of the world;
- **Export world (.zip)** – one file to move or send;
- **Datapacks in this world** – the world's datapacks;
- **Benchmark in this world** – a performance test in your own world (see [Profiles](/wiki/launcher-profile));
- **Show in folder**.

**Import world** adds a world from a .zip file (for example one exported from another profile, or a downloaded map).

### Backups

All world backups of this profile. **Restore** brings a backup back as a separate world, so the current world stays untouched.

### Screenshots

Screenshots taken in the game (F2). You can open one, show it in its folder, delete it, or **share it by link**: the file goes to the SlashClient website and the link is copied to the clipboard. The link works for 30 days; **My links** lists your links with their view counts and lets you delete them sooner.

### Clips

Clips are the last seconds of gameplay saved with F8. Turn them on in the game's HUD settings (Right Shift → Clips). In the launcher you can play a clip, share it by link, or trim it:

- **Trim clip** – drag the **Start** and **End** handles (arrow keys move one frame);
- **Preview the part** plays only the chosen part, in a loop;
- **Save a trimmed copy** saves a new file next to the original with no loss of quality, and **Save and share** gives you a link straight away.

## Configs

The **Configs** tab edits your mods' config files (the config folder) without leaving the launcher.

- On the left the file list with a search box, on the right an editor with syntax colouring.
- The launcher checks the file as you type (**Syntax OK** or what's wrong).
- **Save** writes the changes, **Restore defaults** deletes the file so the mod creates it anew, and the arrow undoes unsaved changes.
- If the file changes on disk (say, the game overwrote it), the launcher warns you.
