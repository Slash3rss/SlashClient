# Keys and presets

## Keys window

All of SlashClient's keys in one place: **Right Shift → Settings → Extras → Keys**. Click a key and press a new one (or a mouse button); **Esc** unbinds it. The arrow beside it brings back the default.

![SlashClient's keys window](hud-okno-klawiszy.webp)

They are the same keys as in the game's controls, so a change in one place shows at once in the other. When another function (the game's or another mod's) uses the same key, a warning shows under it. A module's keys can also be set at the top of its settings page.

## Key presets

Save all your current keys (the game's, SlashClient's and other mods') under a name – "PvP" and "Building", say – and load them with one click. **Right Shift → Settings → Extras → Key presets**.

![Key presets](hud-presety-klawiszy.webp)

- Type a name and click **Save current**.
- **Load** by a preset puts its keys back; the one in use is marked "in use".
- The bin deletes a preset (click twice).
- The **Next key preset** key (none by default) goes through them in turn.

Presets live in a file of their own, so a HUD share code does not carry them. A key a preset does not know (from a mod added later) stays as it is.
