# Changelog

Read what is new in every release of the SlashClient launcher and the SlashClient HUD mod at [slashclient.pl/changelog](https://slashclient.pl/changelog) (in Polish: [/zmiany](https://slashclient.pl/zmiany)).

![The changelog (Polish version)](strona-zmiany.webp)

## On the website

- Each release has a **SlashClient X.Y.Z** heading, a date and a list of changes. The newest is at the top.
- Notable releases carry a **New** badge – the same badge shows on the home page.
- Each release has its own link, e.g. `slashclient.pl/changelog#0.9.69`.
- The page holds 25 releases; open older ones with **Older releases**.

## In the launcher

The launcher shows the same notes:

- after an update – the **What's new in SlashClient …** window (turn it off in **Settings**: **Show "What's new" after updates**),
- on the **Play** tab – the **Launcher news** card,
- in **Settings** – the **Changelog** button with every release.

Players with the launcher in English see the notes in English when a release has an English version.

> Test (beta) versions do not appear in the changelog. Only launchers with the beta channel switched on get them.
