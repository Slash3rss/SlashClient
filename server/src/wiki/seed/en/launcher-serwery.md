# Servers

The **Servers** tab is a list of Polish Minecraft servers from [lista.slash3rss.dev](https://lista.slash3rss.dev) with live status: player count, ping and description (MOTD) straight from each server.

![The server list](launcher-serwery.webp)

## Searching and sorting

- the search box filters by name or address;
- the mode list (all modes, Survival, SkyBlock…) shows servers with that mode;
- sorting: **Most votes**, **Players online** or name;
- the refresh button fetches the status again, and **Show more** loads more servers.

Servers featured by the list carry a **Promoted** tag and sit at the top. When friends allow it, a **Popular among friends** strip sits above the list ("2 friends play here").

## The server card

Each card shows the icon, name, address, modes, MOTD, players and ping, plus these buttons:

| Button | What it does |
|---|---|
| Thumb with a number | vote for the server (once a day) |
| **Play** | joins the server |
| Copy | copies the server address |
| Website, Discord | open the server's website and Discord, if it has them |

## Voting

Vote with the thumb button. The launcher votes on lista.slash3rss.dev with your Minecraft name, with no captcha, once a day. After voting the button says **Voted today** and shows the time until your next vote. When voting from the launcher isn't available, the button becomes **Vote on the website**.

## Server page

Clicking a server's name opens its page in the launcher: banner, MOTD, **Players now**, **Player record**, votes, **Views**, **Listed since**, the **About** text, modes, versions, a players chart (24 hours, 7 days, 30 days) and player reviews. **Write a review on the website** opens the list's page.

![A server page](launcher-serwer-strona.webp)

## Joining

**Play** opens a profile picker. Profiles that fit the server's version are marked as a match, and the launcher remembers which profile you used on each server and offers it next time. If no profile fits, a **New profile** button creates a suitable one. **Join** starts the game and connects straight away; if the game is already running, it connects that game without restarting.

> You can also join friends right from the [Friends](/wiki/launcher-znajomi) tab when they're on a server or have opened a world to LAN.
