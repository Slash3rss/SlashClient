# SlashClient HUD – getting started

SlashClient HUD is the mod the SlashClient launcher adds to the game. It draws modules on the screen (FPS, coordinates, armour, a minimap and over a hundred more), adds its own menus, a world map, waypoints, friends and chat in game, emotes, clips and dozens of small helpers for the inventory and the chat.

![The HUD in game: FPS, CPS, coordinates, compass, minimap, effects, armour, keystrokes and the item counter](hud-hud-w-grze.webp)

## Opening the HUD menu

- **Right Shift** in a world opens the layout editor: drag modules with the mouse, and the **Settings** button in the middle opens the window with every module and extra.
- SlashClient's main menu and pause menu have a HUD button that opens the same settings window.
- Change the key in the **Keys** window (Settings → Extras → Keys) or in the game's controls ("Edit HUD").

More about the editor: [HUD menu and editor](/wiki/hud-edytor).

## What is on from the start

After the first start you see **FPS**, **Ping** (on servers), **CPS**, **Coordinates**, **Effects**, **Armour**, **Item counter**, **Target**, **Attack indicator** and **Keystrokes**. The other modules wait in the settings window – click a card to switch one on. The partner servers' modules (like the dungeon map) are on, but only show where they have something to show.

> With the launcher's **mode for slower computers** on, only the game's own HUD parts are on at first and SlashClient's modules wait until you switch them on. Other players' cosmetics and seasonal effects are hidden too, and the menu background stands still.

## The main keys

| Key | What it does |
|---|---|
| Right Shift | HUD editor |
| C | zoom (hold) |
| O | friends and chat |
| B | waypoint list |
| M | full-screen world map |
| N | emote wheel |
| R | sort a chest or the inventory |
| K | lock a hotbar slot |
| V | F5 camera distance (hold and scroll, once switched on) |
| Left Alt | freelook (hold, once switched on) |
| F6 | instant replay (once switched on) |
| F8 | save a clip (once switched on) |
| F9 | light level overlay |

The full list and how to change them: [Keys and presets](/wiki/hud-klawisze).

## Game versions

The mod is built separately for every supported Minecraft version (Fabric). The launcher picks the right file by itself.

| Game versions | Notes |
|---|---|
| 26.3 | everything, including the SkyUp.pl modules and the mouse over VNC |
| 26.2, 26.1–26.1.2 | everything except the 26.3-only features |
| 1.21.11, 1.21.9–1.21.10, 1.21.6–1.21.8, 1.21.5, 1.21.4 | the full HUD, maps, chat, friends |
| 1.21–1.21.1, 1.20.5–1.20.6 | no wings, pets and some of the cosmetics drawn on the player model |
| 1.20.3–1.20.4 | as 1.20.5–1.20.6, and no action bar box in the editor |
| 1.20.1 | the oldest supported version; no action bar box in the editor |

Only on 26.3:
- the SkyUp.pl modules and windows (tasks, fish counter, SkyCase, wardrobe, SkyUp XP calculator, fish atlas, SkyUp wiki, plan of the week, shamanism, GUI dump) – see [SkyUp.pl modules](/wiki/hud-skyup);
- **Mouse over VNC**;
- switching the dungeon map's view with H (on older versions this key is unbound).
