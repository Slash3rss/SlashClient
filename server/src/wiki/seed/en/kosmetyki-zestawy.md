# Sets

A set is a few cosmetics from different slots with one theme – for example **Dragon**: a dragon cape, wings, elytra, horns, tail, shield and bow. The **Wear the set** button puts on all the parts you have at once. The missing parts say how to get them.

![The Sets tab on the account page (Polish interface)](kosmetyki-zestawy.webp)

## Where the sets are

- **Launcher**: **Accounts** → **Cosmetics** → **SlashClient** → the **Sets** tab (after all the slots). Hovering over a set tries it on the figure.
- **Launcher, shop**: click your Sparks in the top right corner of the window → **Shop** → **Sets**. Here sets change the look of the whole account.
- **Game**: **Esc → Cosmetics** → **Sets**.
- **Website**: [Account](https://slashclient.pl/account) → **Cosmetics** → **Sets**.

## What a set shows

| Part | What it means |
|---|---|
| Name and a counter, e.g. **4/7** | How many of the parts you own. When you have them all, the counter turns blue. |
| Parts | Pictures of the items. Missing ones are dimmed, with a lock; shop items show their price in Sparks and can be bought right there. |
| **Wear the set** | Puts on every part you own. Once you wear them, the button says **Worn**. |
| The list below | How to get the missing parts: a shop price, an achievement, a rank or supporting the project. |

> A set puts on only the parts you have. The other slots stay as they were.

## A character's set

That is something else than the sets above: each Minecraft account can wear **its own set of cosmetics** or **the whole account's set**. See [Cosmetics: how to wear them](/wiki/kosmetyki-wstep).
