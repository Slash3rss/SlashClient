# Wynik benchmarku

Benchmark w launcherze mierzy, jak szybko działa Minecraft na Twoim komputerze. Wynik możesz udostępnić linkiem **slashclient.pl/benchmark/…** – na przykład, żeby porównać się ze znajomymi albo poprosić o pomoc z wydajnością.

![Udostępniony wynik benchmarku](strona-benchmark.webp)

## Jak udostępnić

1. W launcherze otwórz profil i kartę **Wydajność**, a potem **Uruchom benchmark**.
2. Po pomiarze kliknij ikonę **Udostępnij wynik ze specyfikacją komputera**.
3. Link kopiuje się do schowka.

Konto nie jest potrzebne, a wynik jest anonimowy. Ze sprzętu zapisują się tylko nazwy: procesor, karta graficzna, ilość RAM, system i Java.

## Co widać na stronie

| Część | Co pokazuje |
|---|---|
| Nagłówek | karta graficzna i procesor, rodzaj pomiaru (**scena testowa** albo **własny świat**), data |
| Wynik | **FPS średnio**, **1% low**, **0,1% low**, liczba przycięć, użycie procesora i karty graficznej |
| **Sceny** | FPS w każdej scenie testowej: Las, Panorama, Wioska, Woda, Stworzenia, Cząsteczki, Noc |
| **Komputer** | procesor, karta graficzna, RAM (i ile dostała gra), system, Java |
| **Gra** | wersja Minecrafta, zasięg renderowania, rozdzielczość, VSync, liczba modów |

Przyciski: **Kopiuj link** i **Zmierz swój komputer** (prowadzi do pobrania SlashClient).

> **1% low** to średni FPS z najwolniejszego 1% klatek. Im bliżej średniej, tym płynniej gra działa.

Link działa przez rok.
