# Publiczny profil gracza

Każdy gracz SlashClient ma profil na stronie pod adresem **slashclient.pl/u/*nick***. Pokazuje postać w kosmetykach, statystyki, osiągnięcia i więcej – tyle, ile gracz zechce pokazać.

![Publiczny profil gracza](strona-profil.webp)

## Co jest na profilu

- postać 3D w noszonych kosmetykach, nick, rangi, odznaka wsparcia i ramka awatara wspierających;
- [klan](/wiki/spolecznosc-klany) i [społeczności](/wiki/spolecznosc-spolecznosci) (linki do ich stron), nicki kont Minecraft;
- „W SlashClient od …” oraz „Teraz online” albo „Ostatnio online: …”;
- statystyki: godziny gry, seria dni teraz i najdłuższa, dni gry, serwery, Iskry, znajomi, osiągnięcia;
- sekcje **Osiągnięcia**, **Kosmetyki**, **Serwery** i **Streamy** (z odtwarzaczem, gdy jesteś na żywo).

Na swoim profilu masz też przyciski **Jak widzą inni** (podgląd tego, co widzą inni) i **Prywatność**. Każdy może skopiować link przyciskiem **Kopiuj link**.

## Jak otworzyć swój profil

- **Strona**: [Konto](https://slashclient.pl/konto) → **Prywatność** → **Zobacz swój profil**.
- **Launcher**: **Znajomi** → **Konto i profil** → **Profil na stronie** (**Zobacz swój profil**, **Kopiuj link**).
- Profil znajomego otworzysz w rozmowie z nim przyciskiem **Pokaż profil**.

## Prywatność profilu

Na [koncie](https://slashclient.pl/konto), w karcie **Prywatność** (albo w launcherze w **Prywatności profilu**):

### Kto widzi profil

| Opcja | Kto widzi |
|---|---|
| **Wszyscy** (domyślnie) | każdy z linkiem, także bez logowania |
| **Znajomi** | tylko Twoi znajomi z SlashClient (zalogowani) |
| **Tylko ja** | nikt poza Tobą |

### Co jest na profilu

| Element | Domyślnie |
|---|---|
| Statystyki (godziny gry, serie, dni gry) | włączone |
| Osiągnięcia | włączone |
| Noszone kosmetyki | włączone |
| Klan | włączony |
| Społeczności (tylko publiczne, które zostawisz włączone w launcherze) | włączone |
| Konta Minecraft (nicki) | włączone |
| Liczba znajomych | włączona |
| Serwery, na których grasz | **wyłączone** |
| Kiedy ostatnio byłeś online | **wyłączone** |
| Streamy | włączone |

**Pozwól wyszukiwarkom (Google itp.) pokazywać mój profil** jest domyślnie wyłączone i działa tylko przy opcji **Wszyscy**.

> Ty zawsze widzisz cały swój profil. Żeby sprawdzić, co widzą inni, kliknij **Jak widzą inni**.

## Gdy profil jest ukryty

Gość zobaczy „Profil prywatny”, „Tylko dla znajomych” (z przyciskiem logowania) albo „Nie znaleziono gracza”. Moderatorzy mogą ukryć profil, który łamie zasady – właściciel widzi wtedy o tym komunikat.
