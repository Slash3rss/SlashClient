# SlashClient HUD – pierwsze kroki

SlashClient HUD to mod, który launcher SlashClient dokłada do gry. Rysuje na ekranie moduły (FPS, współrzędne, pancerz, minimapę i ponad sto innych), dodaje własne menu, mapę świata, waypointy, znajomych i czat w grze, emotki, klipy oraz dziesiątki drobnych udogodnień w ekwipunku i czacie.

![HUD w grze: FPS, CPS, współrzędne, kompas, minimapa, efekty, pancerz, klawisze i licznik przedmiotów](hud-hud-w-grze.webp)

## Jak otworzyć menu HUD

- **Prawy Shift** w świecie otwiera edytor układu: moduły przeciągasz myszką, a przycisk **Ustawienia** na środku otwiera okno ze wszystkimi modułami i dodatkami.
- W menu głównym i w menu pauzy SlashClient jest przycisk HUD, który otwiera to samo okno ustawień.
- Klawisz zmienisz w oknie **Klawisze** (Ustawienia → Dodatki → Klawisze) albo w sterowaniu gry („Edytuj HUD”).

Więcej o edytorze: [Menu i edytor HUD](/wiki/hud-edytor).

## Co jest włączone od razu

Po pierwszym uruchomieniu widać: **FPS**, **Ping** (na serwerach), **CPS**, **Współrzędne**, **Efekty**, **Pancerz**, **Licznik przedmiotów**, **Cel**, **Wskaźnik ataku** i **Klawisze**. Reszta modułów czeka wyłączona w oknie ustawień – wystarczy kliknąć kartę, żeby ją włączyć. Moduły serwerów partnerskich (np. mapa dungeonu) są włączone, ale pokazują się tylko tam, gdzie mają co pokazać.

> Gdy w launcherze włączysz **tryb dla słabszych komputerów**, na start włączone są tylko części interfejsu gry, a moduły SlashClient czekają, aż je sam włączysz. Do tego nie widać kosmetyków innych graczy ani efektów sezonowych, a tło menu stoi w miejscu.

## Najważniejsze klawisze

| Klawisz | Co robi |
|---|---|
| Prawy Shift | edytor HUD |
| C | przybliżenie (trzymaj) |
| O | znajomi i czat |
| B | lista waypointów |
| M | mapa świata na cały ekran |
| N | koło emotek |
| R | sortowanie skrzyni lub ekwipunku |
| K | blokada slotu paska |
| V | odległość kamery w F5 (trzymaj i kręć kółkiem, po włączeniu) |
| Lewy Alt | freelook (trzymaj, po włączeniu) |
| F6 | natychmiastowa powtórka (po włączeniu) |
| F8 | zapis klipu (po włączeniu) |
| F9 | nakładka poziomu światła |

Pełna lista i zmiana klawiszy: [Klawisze i presety](/wiki/hud-klawisze).

## Wersje gry

Mod jest budowany osobno na każdą wspieraną wersję Minecrafta (Fabric). Launcher sam dobiera właściwy plik.

| Wersje gry | Uwagi |
|---|---|
| 26.3 | wszystkie funkcje, w tym moduły SkyUp.pl i myszka przez VNC |
| 26.2, 26.1–26.1.2 | wszystko poza funkcjami tylko dla 26.3 |
| 1.21.11, 1.21.9–1.21.10, 1.21.6–1.21.8, 1.21.5, 1.21.4 | pełny HUD, mapy, czat, znajomi |
| 1.21–1.21.1 | bez skrzydeł, pupili i części kosmetyków rysowanych na modelu gracza |
| 1.20.1 | najstarsza wspierana wersja; bez paska akcji w edytorze |

Funkcje tylko dla 26.3:
- moduły i okna SkyUp.pl (zadania, licznik ryb, SkyCase, garderoba, kalkulator XP SkyUp, atlas ryb, wiki SkyUp, plan tygodnia, szamaństwo, zrzut GUI) – zobacz [Moduły SkyUp.pl](/wiki/hud-skyup);
- **Myszka przez VNC**;
- przełączanie widoku mapy dungeonu klawiszem H (na starszych wersjach ten klawisz jest nieprzypisany).
